# ha-echomuse

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Превратите имеющуюся **Echo Dot 2** в голосовой терминал Home Assistant с
EchoMuse и emOS. Это независимый проект: воспроизводимое развёртывание,
восстановление, локальное управление домом и инструкции. Это не официальная
сборка EchoMuse и не универсальная прошивка для всех Echo.

## Возможности

- Сборка по закреплённым версиям; **скрипт сборки сам ничего не прошивает**.
- Assist через ESPHome, управление музыкой, объявления, таймеры, начало озвучки
  до конца генерации и прерывание фразой пробуждения при поддержке компонентов.
- Локальный API для Ollama: состояния, управление явно разрешёнными устройствами,
  статистика Recorder и ограниченные отчёты об энергии без изменения устройств.
- Отдельное зашифрованное подключение Bluetooth-прокси для BLE.
- README на пяти языках и выбор языка ответа из фиксированного списка.
  Примеры нативных запросов состояния — на английском и русском;
  [точные границы поддержки](docs/i18n.md).

## Что потребуется

Документированная модель — **Echo Dot 2 / RS03QR (biscuit)**. Перед изменением
загрузки проверьте модель, ОС, разделы и резервную копию именно этой колонки.
Другие поколения и полноразмерные Echo этой инструкцией не проверены.
Нужны стабильное питание, USB-кабель с передачей данных и совместимый хост
восстановления: одного Wi-Fi для восстановления недостаточно.

Также нужны Home Assistant, речевой конвейер Assist и EchoMuse Controller.
Music Assistant, Plex, Ollama и сервис энергии нужны только для соответствующих
дополнительных функций. **Не применяйте манифесты с заглушками без настройки.**

## Порядок установки

1. Проверьте [совместимость](docs/compatibility.md) и прочитайте всю
   [инструкцию миграции](docs/migration.md), включая откат.
2. Разверните [контроллер](docs/controller.md) с приватным постоянным хранилищем,
   TLS и отдельными учётными данными каждой колонки.
3. Проверьте [закреплённые артефакты](upstream-lock.json), сохраните резервную
   копию устройства и подготовьте его образ через [build_emos.py](scripts/build_emos.py).
   Копия другой колонки не подходит.
4. Выполните USB-установку, подтвердите устройство в контроллере и добавьте его
   голосовой endpoint через интеграцию **ESPHome** в Home Assistant.
5. Назначьте конвейер Assist, язык STT и голос TTS. При необходимости настройте
   [управление домом](docs/home-control.md) и [отчёты энергии](docs/energy-assist.md).
6. Добавьте актуальные сущности в [Lovelace](docs/dashboard.md).
   [BLE-прокси](docs/bluetooth-proxy.md) подключается отдельно.
7. Пройдите [приёмочную проверку](docs/operations.md) каждой колонки до
   следующей миграции. Связь с контроллером ещё не подтверждает слышимый ответ.

## Ежедневное использование

Управление — через защищённый входом веб-интерфейс контроллера и root Console:
[доступ и учётные данные](docs/device-access.md). Универсальный логин SSH/Telnet
проект не создаёт; восстановление описано отдельно.

Обе пилотные Dot переведены с Hey Jarvis на обученную локально **«Привет, Мышка»**.
См. [обучение, установку и ограничения проверки](docs/russian-wake-word.md).
Прошивка использует одну активную модель. Персональные веса не входят в
репозиторий; перевод README сам по себе не устанавливает фразу пробуждения.
[Голосовые функции](docs/voice-features.md) объясняют прерывание и потоковую речь.
[Диагностика музыки](docs/music-troubleshooting.md) — проверку источников,
буферизацию, остановку и паузу именно на исходной колонке.
**iBeacon Tracker** обрабатывает BLE-маячки, а не создаёт дополнительный прокси.

## Что проверено и какие есть ограничения

Зафиксированная конфигурация: emOS **0.10**, EchoMuse **2.18.0**, Controller
**2.26.0**, Home Assistant **2026.10.0**. Это историческая проверенная база, а не
обещание последних версий или текущего состояния устройств. Обе миграции и
русские ответы вблизи колонки проверялись; дальнее распознавание и долговременная
надёжность имеют ограничения. См. [журнал](docs/deployment-record.md),
[проверки речи](docs/russian-voice-validation.md) и [измерения задержки](docs/architecture.md).

Текущий голос в зафиксированной конфигурации — **Silero Baya**. Управление домом
идёт через локальную Ollama, но STT использует FCC cloud speech: **весь конвейер
не является автономным**. Другому языку нужны совместимые STT, модель, TTS и
отдельная проверка на слух. Домашние данные нельзя отправлять в дополнительный
облачный маршрут общих вопросов: [границы приватности](docs/home-control.md).
